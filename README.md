# Namanga School: learning files

Public learning files used by the **Namanga Secondary School** Android app.
They are copies of the resources already published free on the school website
(https://namangawebsite.freepage.cc), stored here as GitHub Release assets so the
app can download them.

- Each release holds one category (notes, summaries, theory, practical, others,
  tasks, gallery, school exams by Form).
- Asset names start with the first 12 characters of the file's SHA-256.

Do not upload files here by hand: the app's migration tool manages them.
